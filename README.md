# Teste de Desenvolvimento Web

Este projeto foi desenvolvido como parte de um teste técnico para vaga de desenvolvimento web.  
A aplicação consiste em uma API REST para gerenciamento de colaboradores e um frontend simples para consumo da API.

---

## Tecnologias Utilizadas

### Backend
- Python
- Flask
- MySQL
- Flask-CORS

### Frontend
- HTML5
- CSS3
- JavaScript (Fetch API)

---

## Como rodar o backend?

1) cd Teste_Desenvolvimento
2) cd backend
3) pip install -r requirements.txt
4) python app.py
O backend será executado em: http://127.0.0.1:5000

---

## Como rodar o frontend?

Abra o arquivo frontend/index.html utilizando Live Server ou diretamente no navegador utilizando a URL: http://127.0.0.1:5500/Teste_DesenvolvimentoWEB/frontend/index.html
